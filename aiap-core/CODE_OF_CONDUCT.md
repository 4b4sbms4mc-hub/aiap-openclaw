# Code of Conduct

AIAP welcomes technical participation from individuals and organizations with different backgrounds and viewpoints.

Participants are expected to:
- discuss technical disagreements on their merits;
- avoid harassment, threats, discrimination, and personal attacks;
- respect security disclosure processes and privacy;
- accurately represent project status, authorship, compatibility, and test results;
- disclose material conflicts of interest when they affect protocol decisions.

Project maintainers may moderate project spaces to protect constructive technical collaboration.
