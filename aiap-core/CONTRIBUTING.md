# Contributing to AIAP

AIAP welcomes issues, pull requests, implementation reports, adapters, test vectors, and interoperability feedback.

## Contribution license
By submitting a contribution, you represent that you have the right to submit it and agree that the contribution may be distributed under the license already applicable to the affected file or directory:

- Apache-2.0 for code, Schemas, SDKs, tests, examples, and reference implementations.
- CC BY 4.0 for specifications, whitepapers, and prose documentation.

No copyright assignment is required under the current governance model.

## Normative protocol changes
A normative change should include:
1. problem statement;
2. proposed normative behavior;
3. backward-compatibility impact;
4. security and privacy analysis;
5. Schema impact;
6. tests or test vectors where practical.

## Core versus Extension
New functionality should be implemented as an Extension unless interoperability requires it to be part of the stable Core.

## Security
Do not publish exploitable vulnerabilities before following `SECURITY.md`.
