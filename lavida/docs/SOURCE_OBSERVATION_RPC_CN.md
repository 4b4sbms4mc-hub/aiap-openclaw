# 实验性源观察消息边界

作者：Wang Lu。2026-11-10。`source_observation_rpc.py` 只定义合成实验中的消息边界，没有监听器、SSH服务、NAS绑定或生产授权。它不会替换已安装的连通性探针；真实NAS仍只报告source_observation_available=false。

## 请求和签名验证

请求最多1024字节，严格UTF-8和无重复键JSON，字段只能为profile、op、nonce和checkpoint_sha256；只接受observe操作及64位小写十六进制nonce/pin。源目录和pin对应的检查点文件由可信构造配置指定，注册映射复制后使用，最多16项；未知pin、额外路径/命令、错误操作等在源观察调用前拒绝。这个受信配置本身不是远程授权机制。

适配器复用既有observe_source：校验检查点摘要/签名/结构及身份，将当前只读SQLite治理快照与检查点比较，在快照内使用合成源Owner Key签署原有30秒观察格式。未重定义签名域、Owner信任或见证协议。适配器在序列化输出前再次校验观察结构/签名/nonce/pin，避免错误observer返回小型额外内容。响应最多4096字节，不返回记忆正文或密钥；失败仅返回统一unavailable，不反射输入、路径或异常文本。

客户端仍要独立校验本地检查点、源观察签名、nonce、pin、登记身份和时间窗口，成功后才交给既有见证/reader。连通性probe的false标记、普通成功响应或服务端字符串都不能成为源证明。nonce消费及最终重放拒绝仍由现有reader执行，本模块的纯验证函数不单独保存已用nonce。

这是时点观察，不是写入租约。观察之后并发修改、未被见证观察的离线变更后整源回退，以及源/见证/reader同时回退的既有限制没有消失。

## 实验验证与生产缺口

8项新测试覆盖签名往返并接入现有见证/reader、源文件不变/私密正文不输出、旧检查点/源变更、过期/篡改/新挑战下旧响应、消息边界、错误脱敏及注册映射别名修改。另有4项stdio子进程测试覆盖有效签名响应、非法请求不启动进程、挂起/持续输出上限、错误退出/无效签名及stderr不回显。所有数据和签名私钥均由临时合成fixture生成；没有读取真实NAS/Keychain或更换已批准凭据。合计192项。

生产接入前仍需具体设计和验收：受限认证调用者、检查点可信登记/更新及其敏感治理元数据范围、只读检查点生成方案、固定执行环境和Schema、生产进程树/执行环境控制、独立密钥用途审阅、最小权限帮助器及精确安装/回退。source_observation_transport.py现已限制直接子进程等待最多15秒及stdout4096字节，异常时kill/wait并关闭管道；argv仍必须来自可信配置，stderr丢弃。这个等待限制不等于本地检查点/密码学验证的CPU总上限，也不保证任意孙进程清理，不是已部署的生产worker。现有export_checkpoint实验函数可能读取记忆记录做一致性检查，不能未经新范围批准直接用于生产“只读登记”。

既有observe_source明确仅用于合成实验，其构造参数不是生产隔离屏障；不要因为此适配器存在就指向真实/data或读取Owner私钥。当前没有新增sudoers/Docker、生产源签名、守护服务或恢复激活。

执行归属：LM Studio qwen2.5-coder-14b-instruct-mlx给出nonce格式、已登记pin和可信路径配置的审查点，Codex复核采纳对应测试；其“已知恶意摘要”措辞未作为黑名单机制采用，而是使用严格pin及签名验证。Codex完成最终实现、测试及复核；本轮无云端模型调用。模型结束且idle后卸载，ps确认空。
