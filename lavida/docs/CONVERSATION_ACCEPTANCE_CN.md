# 本地模型真实对话验收

作者：Wang Lu。2026-11-09。组件保持 La Vida 0.3.5 / Core 0.2.0。

本次在真实 OpenClaw 2026.9.4 中接入 LM Studio 的 `qwen/qwen3.5-9b`，验证模型通过正常对话选择插件工具。Codex 负责隔离环境、合成数据、独立 Owner 审批和验收；本地模型实际完成工具选择与回答。未调用云端模型。

## 验证方法

测试沿用 [Gateway 新安装和隔离恢复夹具](GATEWAY_ACCEPTANCE_CN.md)，增加可选 `--conversation-model`。Gateway 只监听 loopback，使用随机 operator token。模型服务必须是 loopback 的 `/v1` 端点；不接入个人配置或外部渠道。所有状态、会话、凭证、私钥和快照在临时目录中生成，结束时清理。此脚本不加载、切换或卸载 LM Studio 模型。

对话通过 `/v1/chat/completions` 运行正常 agent turn，使用宿主认证产生的 Owner 上下文。测试不提供客户端工具，不指定 `tool_choice`，不模拟宿主注册或模型输出。唯一允许的工具为 La Vida 的 status/search/propose；随机测试答案不会写入工作区提示文件。

本地模型使用 `tools.toolSearch: false`，直接展示这三个小工具的 Schema。OpenClaw 对 LM Studio 默认启用动态工具目录；复测中模型曾把目录调用包装误当成工具参数，造成召回失败。因此本配置明确关闭该呈现层，不改变工具授权，也不强制选择某个工具。默认目录模式的稳定性仍未验收，不能把本配置结果推广到该模式。

另一项失败是模型把整句问题或翻译附加词作为默认字面检索的 query，导致已批准对象未命中。0.3.5 同时修正检索说明：先复制用户给出的精确项目标识或短关键词，空结果再缩短关键词，不把无命中当作不存在的证明。此修订没有默认启用语义检索。

| 项目 | 通过条件 |
| --- | --- |
| 自然语言记忆请求 | 中文请求后 Core 出现一条由 adapter 凭证提交的待批准候选，内容含本轮随机码 |
| 审批说明 | 模型答复说明仍待审批，候选尚不能从有效记忆中检索 |
| 审批前新会话 | 未向新会话提供答案，不能返回待批准随机码 |
| 独立批准 | Owner 管理客户端读取候选并批准，插件不能自批准 |
| 批准后新会话 | 仅询问项目名，模型准确返回随机码 |
| 拒绝与空间隔离 | 已拒绝候选与 life 空间有效记录的随机码均不能从 general 对话返回 |
| 隔离恢复 | 原目录离线，恢复后对象 ID/版本不变；另一个新会话能召回原随机码 |
| 撤销凭证 | 撤销 adapter grant 后，全新会话报告不可访问且不返回随机码 |

这些会话均由同一测试 Owner 明确绑定到同一个 general 空间；增加测试会话绑定不扩大空间权限。Owner 审批由独立管理客户端自动执行，仅针对本轮合成数据，不代表用户对任何真实记忆或生产变更的批准。

## 复现

先检查 `lms ps`。目标模型已单独加载则复用；否则等待旧任务结束、卸载旧模型，并再次检查其他模型均已卸载后，才加载目标模型。本地同时只加载一个模型。建议上下文 32768，服务地址按实际值设置；本轮端口为 1235。模型下载与加载由操作者单独完成。

```sh
python scripts/package_lavida.py
python scripts/check_openclaw_gateway.py \
  --openclaw-entry /absolute/isolated/host/node_modules/openclaw/openclaw.mjs \
  --release-zip dist/LaVida_for_OpenClaw_0.3.5.zip \
  --conversation-model qwen/qwen3.5-9b \
  --model-base-url http://127.0.0.1:1235/v1 \
  --output .validation/conversation.json
```

输出只包含模型和组件版本、测试包摘要、检查结果及限制，不发布测试答案、对话原文或模型推理内容。失败的重跑先清除旧成功报告，不能依靠残留报告宣称通过。

## 适用范围

首轮 0.3.4 英文探针通过，但中文请求发现模型将“自动提案关闭”误解为“不能手动提案”，没有创建候选并编造了 `/approve`。这项失败没有被记为通过。0.3.5 明确手动候选入口和独立 Owner 审核边界，再以相同中文请求及拒绝/life 负例复测。改变的是插件提示和工具说明，不放宽认证、空间或批准规则。

结果仅适用于记录的模型、版本组合、提示和配置；不证明所有模型、所有表述或长期对话均可靠。现有 GitHub CI 默认不运行真实本地模型，只复测不依赖模型的 Gateway 部分，并在无外部网络的单容器 Docker 夹具内重复新安装和恢复。该夹具同时启动两个真实进程，未公开端口，也不是生产部署镜像或现有 NAS 实测。机器可放在本机隔离目录或虚拟机，无须全局安装或注册服务。

仍未证明完整 Docker/NAS OpenClaw 部署、组织隔离、完整生命周期、跨 Runtime 安全迁移或旧备份恢复时的当前删除/撤销治理。当前停机快照内保留的授权不能代替后两项验收。
