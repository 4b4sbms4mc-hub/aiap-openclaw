# AIAP v0.3.0 Public Release

**Release:** v0.3.0  
**Author / Project Maintainer:** Wang Lu  
**Status:** Public normative draft and reference implementation release

## Highlights
- English AIAP Whitepaper v0.3
- Core Identity Specification
- Ownership Specification
- Secure Avatar Transfer Specification
- Key Management Specification
- JSON Schema Draft 2020-12 Core Schemas
- reference validator and Transfer Certificate helpers
- public open-standard policy
- governance, IP, patent, trademark, contribution, security, and conduct policies
- GitHub CI tests
- separate OpenClaw-compatible distribution

## Standard maturity
v0.3.0 is suitable for public implementation experiments and interoperability testing. It is not yet declared a frozen v1.0 standard.

## Compatibility claims
Implementers should identify the exact AIAP version they implement. Future public conformance tests will be the preferred basis for stronger compatibility claims.
