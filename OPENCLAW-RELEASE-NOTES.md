# AIAP v0.3.0 OpenClaw-Compatible Public Release

This distribution packages the AIAP v0.3 Core together with an OpenClaw-compatible Agent Plugins bundle, AIAP Skill instructions, and a stdio MCP adapter.

It does not fork OpenClaw and does not claim endorsement or certification by the OpenClaw project.

The AIAP technical standard remains implementation-neutral. OpenClaw is one reference integration target.
